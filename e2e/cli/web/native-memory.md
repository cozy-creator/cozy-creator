The scale test keeps its raw RSS readings and peak RSS bars on every OS. On Darwin, its closed-project +256MiB budget measures current kernel-charged physical footprint and requires known project DB closure with the same PID and exact process-start identity. An unavailable or ambiguous observation fails. Linux and Windows retain the RSS comparison.

This is test measurement, not application memory policy. It does not collect, trim, tune, suspend or walk the target heap. The small helper calls `proc_pid_rusage(RUSAGE_INFO_V0)` and emits only PID, exact uint64 start identity, physical-footprint bytes and resident bytes. Byte counts must be positive safe integers. Start identity stays decimal text.

RSS includes pages Darwin can reclaim without charging the process's physical footprint. The pinned mimalloc v3 defaults to anonymous mapping tag100 (which Darwin calls IOAccelerator) and uses `MADV_FREE_REUSABLE` for decommit. Darwin removes reusable-page footprint charges and restores them on reuse. The region label alone does not prove GPU ownership or that every page was purged. See the [Apple accounting implementation](https://github.com/apple-oss-distributions/xnu/blob/xnu-11417.140.69/osfmk/arm64/sptm/pmap/pmap.c#L7022) and [typed API](https://github.com/apple-oss-distributions/xnu/blob/xnu-11417.140.69/libsyscall/wrappers/libproc/libproc.h#L99).
