Seed tensors are actual Loop-carried mutable state. It proves the observed partial writes and that no legacy/backend fallback runs after acceptance. This is explicitly instrumented functional evidence, not a timing benchmark. Compact boundary diagnostics survive log limits; each case also logs its measurements before assertions. A second same-process `cleanup` request verifies request-owned native keys retired.
