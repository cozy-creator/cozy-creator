An ended machine's logs can be read again (cl-1012, Paul 11-15: "you can log ended machines yeah sure"): `cozy machine logs <m>` answers the newest 200 of its own lines (boot, software, service, GPUs, disk, Hub lease, end), which Calcifer kept from its Status stream. It takes the machine's name when no live machine has it, or its rental id. No line with a run or a project's content is kept: a failed run's traceback stays in its run record (`cozy run watch <run> --once`). The lines go with the machine's record.
