A rental no longer sits on a host that downloads slowly. Its machine holds its first download to the floor its Hub names (800 Mbit/s): under it for 30 s, past the first 10 s, it tells the Hub once, and the Hub ends that host uncharged and places the rental on another, at most twice. Its runs return to Cozy's queue as their next attempt, saying "its host downloaded too slowly", and `cozy machine ls` shows it "moving to a faster host" until it serves again. A host that keeps pace reports the pace its link sustained, once, so the Hub ranks hosts by measured links. The rate counts only while the link sets the pace: a lone small file, a stalled read or a download sharing the link with an install is not judged.
