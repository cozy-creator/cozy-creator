`cozy apply -f FILE` merges a file of nodes into the project, each against the rev it was read at: what the file changed is written, what the page changed meanwhile stands, a value both changed is a conflict, and words both edited merge unless the edits overlap; every error with its fix, nothing written on one. It is one edit the page's Undo takes back, and the file is rewritten as the nodes now stand. `cozy diff -f FILE` shows that merge; `cozy delete NAME…` removes nodes as one edit (cl-956).
