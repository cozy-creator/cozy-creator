The page's tools are one list for every machine: the Hub's catalog, kept on disk and read again when a page opens and every 5 minutes while one is open, plus everything this computer has installed and the local code it reads. It never waits on the Hub and carries no note: with the Hub away it lists what's installed. Calcifer tells the page when the list changes (`tools.changed` on `/v1/events`) and the page no longer asks again on a timer. A dev home reads each package of its packages checkout once per change of its source, seen by a file watch, instead of every 30 s behind each list and again for each new or renamed machine.
