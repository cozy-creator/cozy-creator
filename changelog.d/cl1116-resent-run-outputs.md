- A run sent again, moved to a machine that finishes it sooner or retried after its machine failed under it, lands its outputs. Before, Calcifer read them by the run's first name, which the machine doesn't know it by after a resend, so the finished take was lost as `output_gone` (`run_not_found`). Calcifer now has one name per run attempt for everything it asks a machine, so a resent run can't be addressed by a name the machine doesn't know (cl-1116).
