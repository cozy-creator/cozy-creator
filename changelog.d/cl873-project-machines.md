A project can pin its runs to a set of machines. `cozy machine use local,ryuk` (or the page's Run on, now a multi-select) keeps the set in the project, so the CLI and the page agree; every `cozy run` and render in that project goes to whichever of them finishes first, and `cozy machine use` with no machines, or Automatically, goes back to any machine. `cozy run --on a,b` takes a set for one run and overrides the project's. When none of the set can take a run (offline, ended, or it can't run it), the run is refused naming each machine and why; it never goes to another machine. The Run on choice is no longer kept in the browser.
