`cozy model upload <source>:<component>,…` publishes a checkpoint of those components alone: a VAE file is `file.safetensors:vae`, a Hub model's VAE `org/name@1.0.0:vae` (by reference, nothing re-sent). Its card and `cozy model install` hold that component only, and a slot naming it reads it composed with the default model's other components. A part stored alone verifies as the one family whose part it is.
