Every rental of your account is yours to use from any of your computers, whichever one rented it: a run naming no machine (and `--on any`) can go to any of them, the least busy first, and one broken after an update is ended by whichever computer sees it. Cozy moves a rental's software for a run (to a package's Runtime floor, or this cozy's minor) only when no other computer's runs are on it, and a rental another of your computers rented only when you update it by hand (`cozy machine update`). `cozy machine ls` no longer says "rental (other client)", and the page no longer says "Rented by another computer" or hides Keep running and End's usual steps for such a rental. A run still says which computer sent it.
