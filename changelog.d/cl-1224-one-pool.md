Every rental of your account is yours to use from any of your computers, whichever one rented it: a run naming no machine (and `--on any`) can go to any of them, a run there moves it to the Runtime its package needs, and one broken after an update is ended by whichever computer sees it. `cozy machine ls` no longer says "rental (other client)", and the page no longer says "Rented by another computer" or hides Keep running and End's usual steps for such a rental. A run still says which computer sent it.
