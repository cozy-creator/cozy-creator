A function's `estimate=` (cozy-runtime) is read by its plan: its size variables are a request's size in placement, the page's estimate and its run's record (`measurements.size`, rows `cozy package benchmarks` writes), and its `ms` formula over its benchmark rows (`measured(machine)`, `pow`, `sum`, `min`, `max`; crates/needs) times it on a machine with no runs of it, from the row the platform's own estimate picks (`References::estimate`), which also times a function that declares none, each declared variable by its own exponent. On a machine with no GPU a formula's time counts only where it read a CPU row. An expression that can't be read refuses the package at describe and publish (`estimate_invalid`); a run of one says so once and is timed as one without.
