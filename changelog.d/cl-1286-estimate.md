A function's `estimate=` (cozy-runtime) is read by its plan: its size variables are a request's size in `cozy run --estimate`, placement and its run's record (`measurements.size`, rows `cozy package benchmarks` writes), and its `ms` formula over its benchmark rows (`measured(machine)`, `pow`, `sum`; crates/needs) times it on a machine with no runs of it; an expression that can't be read refuses the package (`estimate_invalid`). A function without one is sized and timed as before.
