`cozy run --on new` rents a machine for its run again, quoted and agreed. The price agreed (`POST /v1/run-quotes`) never reached the run since cl-716 B, so any run that would rent was refused `quote_unagreed`; and a project's run (every run, since cl-1028) was refused a rental (`project_remote_execution_unavailable`), its rent reading the run from Calcifer's own store, where a project's run never is. A project's rent order in Calcifer's store names neither the run nor the project: once an encrypted project locks, nothing outside it ties the rental to it.
