Calcifer, TensorD: files go to a machine in one request (cl-1123). Calcifer asks once which files a machine lacks, then sends all of them in a single `PUT /v1/objects`. This covers both a box's guess carrying local code and a render uploading its own inputs. Files over 64 MiB, or files going to a machine older than this release, are uploaded alone in parts, as before. An Orbit box's first guess on a rental had sent orbit and minimax-h3's 392 files one at a time and took 83 s. The Triton sets built into a source checkout still go with it (xs-194): without them, the machine would compile kernels on the render's first call.
