An open encrypted project's running job no longer shows anything its project wrote to anyone outside it. Before, it showed its project's name, its run key (made from that name), its tool, its stage's words, its outputs' file paths, its generated text and its log lines in `cozy machine show` and `cozy --json machine show` from outside the project, in the machines list, and in what another project's page received. Now an outsider sees only that it is there: its run id, its state, its times and its step counts, as `run run-… · running`. Another project's page still reads "Another project's run". A plain project's runs show as before. Until the next release, the machine's list of installed environments still names an encrypted project's own local package (for example `local/said`) to any reader (cl-1253). Inside the encrypted project, `cozy machine show` reads its own runs reduced too; `cozy run ls` keeps every detail.
