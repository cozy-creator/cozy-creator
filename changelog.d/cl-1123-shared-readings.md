Calcifer: unencrypted projects share static readings of local code (cl-1123). Each reading is keyed by the code's tree and the Runtime version that read it, as unencrypted projects already share locks (cl-1011). Before, a fresh project's first guess of a box ran the describer again, about 4.5 s for Orbit. Changed code gets a new tree, so it's read again. An encrypted project keeps its own readings and never reads or writes the shared ones.
