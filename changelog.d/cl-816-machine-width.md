The machine chooses a run's GPU width: a lone job runs wide, queued jobs one GPU each, and `--gpus N` is a request it honours. With several machines, each job goes to the one that quotes the soonest finish (TensorD's `POST /v1/estimate`), a rental before this computer on a tie. `cozy run … --estimate [N]` prints each machine's quote and sends nothing. A render's board shows a job's quoted end until its run, running, says its time left, the same time the page shows. A render's jobs bound for one machine are sent to it together, so it packs them as it quoted them; a machine's quote of a function stands on its own runs of it, local code too. Work goes only to a machine on this cozy's minor: one on another is updated first, and one added from another computer or with runs going is refused with `machine_other_minor`, naming `cozy machine update`. Older machines are no longer served another way: no run sent one by one, no time without a quote, no update after a failure for a machine's age.
