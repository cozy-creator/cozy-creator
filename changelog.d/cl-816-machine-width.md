The machine chooses a run's GPU width: a lone job runs wide, queued jobs one GPU each, and `--gpus N` is a request it honours. With several machines, each job goes to the one that quotes the soonest finish (TensorD's `POST /v1/estimate`), a rental before this computer on a tie. `cozy run … --estimate [N]` prints each machine's quote and sends nothing. A render's board shows a job's quoted end until its run, running, says its time left, the same time the page shows.
