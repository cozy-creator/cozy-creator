- A busy machine's quote counts all the work its runs ahead still have: a run that started on its CPU while its GPU work waits for weights or a GPU (H3's generate and edit) counts in full, after its downloads, not as all but done. A run waiting that way moves to another machine that would finish it clearly sooner, checked at each report of a machine, never back to one it left. `cozy machine show` says how long a machine stays busy as placement counts it (cl-1107).
- A function one machine timed isn't quoted a minute on another: the same card takes that time, another card that time scaled by how the two compare. A rental that hasn't measured its link is quoted at what this account's other rentals from its provider measured, not a flat 100 MB/s (cl-1107).
