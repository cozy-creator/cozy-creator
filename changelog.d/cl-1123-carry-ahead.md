A box's input files go to its rental ahead of Render, in every project, encrypted ones too (cl-1123). Once a box with a tool reads a picture or a video, its file goes to the machine its render would go to, so a 100 MB reference video is there by the time you press Render, and the render sends nothing more. Only to this account's own machines (this computer, or one it rented), over the same pinned, signed link a run uses; nothing goes ahead to a computer added by address. These uploads wait while any render uploads its own inputs, then pick up where they stopped, so they never slow a render down or send a file twice. An edit that keeps the file doesn't restart its upload.
