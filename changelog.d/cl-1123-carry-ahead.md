A box's input files go to its rental ahead of Render, in every project, encrypted ones too (cl-1123). Once a box with a tool reads a picture or a video, its file goes to the machine its render would go to, so a 100 MB reference video is there by the time you press Render, and the render sends nothing more. They go over the same pinned, signed link a run uses: a plain project's to any machine its renders go to, as its tool code always did, and an encrypted project's only to this account's own machines (this computer, or one it rented), never to a computer added by address. These uploads wait while any render uploads its own inputs, then pick up where they stopped, so they never slow a render down or send a file twice. An edit that keeps the file doesn't restart its upload. An encrypted project's own tool code now goes to a rental ahead the same way, so the rental has it installed before Render; before, it went only with its first render there. On this computer it stays in the project's vault.
