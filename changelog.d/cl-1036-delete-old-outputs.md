Upgrading deletes the old landing folder `~/.cozy/outputs` (cl-1036; Paul: "Delete both"). What a registered project shows of it (a `files/` link into it, or a file its lock names whose bytes are only there) is held first and copied into the project at its next open. A project that can't be read yet (locked, or its lock unreadable) keeps the folder, set aside as `~/.cozy/outputs.cut`, until it is read; `cozy doctor` says so and how to let it go. On this computer's machine, old runs from before 0.26 keep their retained outputs only while a header file names their objects (a project's hold or its own latents); the rest go. Homes already cut by the 0.26 RC take both at their next start.
