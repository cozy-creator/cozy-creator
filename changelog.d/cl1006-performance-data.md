Anonymous performance data (cl-1006, Paul 11-15): each published function's run on any machine, local, added or rented, is reported to the Hub for troubleshooting and usage: its function, package release, lane, models, versions, OS release, host memory, GPU, size, times, memory pressure, kernels, outcome, error and warning codes, the stage a failed run was in and whether it was slow. It goes under a random install ID this computer makes, with no credential, so nothing ties it to the account or machine; never prompts, inputs, outputs, names, paths, keys or messages. Reports wait in memory and go together; a batch the Hub doesn't take is dropped. Turn it off in the page's Settings ("Send anonymous performance data"), with `cozy config set send_performance_data false`, or `[calcifer] send_performance_data = false` in config.toml: nothing is sent and the install ID is deleted. Reports no longer feed placement estimates. Replaces the rental-only `POST /v1/rentals/{id}/run-times`.
