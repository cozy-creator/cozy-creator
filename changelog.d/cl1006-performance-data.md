Anonymous performance data (cl-1006, Paul 11-15): each published function's run on any machine, local, added or rented, is reported to the Hub with its function, package, versions, models, GPU, size, times, kernels and outcome. Never its prompts, inputs, outputs, names or keys, and with no credential, so nothing ties it to who ran it. Reports wait in memory and go together; a batch the Hub doesn't take is dropped. Turn it off in the page's Settings ("Send anonymous performance data"), with `cozy config set send_performance_data false`, or `[calcifer] send_performance_data = false` in config.toml. Replaces the rental-only `POST /v1/rentals/{id}/run-times`.
