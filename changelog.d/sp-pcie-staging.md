TensorFS's host tier makes the shared host memory a group of executors stages a Ulysses all-to-all through (`Pages.staging`, mapped by its peers with `Staging.open`): it comes from varena's host number like a retained region's copy, weight pages shed first and idle peers asked, and is held there until it closes, never given back. The host's ledger page counts it, so no tier pins into it and the reserve sees it.
