`cozy render NAME… [--on M,…] [-n N] [--new] [--outdated] [--pickup '<shot.1>@243']` renders nodes as the page's Render does, on its route: only what is missing or out of date among the named nodes and what they read, those first, a cut's too; `--new` renders named nodes that are current, `-n` is takes per named node, `--outdated` renders approved takes that are out of date. A node already rendering is joined, so a rerun never pays twice, and stopping the command never cancels the render. One line per take as it lands, then `next:`; `nothing to render: …` when all is current; no prompts off a terminal (cl-956).
