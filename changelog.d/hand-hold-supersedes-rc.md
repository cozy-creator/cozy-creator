A machine held by hand stays on what you named. `cozy machine update <machine> --runtime … --tensorfs … --tensord …` now cancels the updates Cozy itself had queued for that machine, such as a dev home rental's move to the open RC at boot, so none of them runs after yours. `cozy machine show` and `cozy machine ls` report what the machine runs. When that differs from its hold, they say so: `beerus: runs Runtime 0.48.0.dev2319, though held by hand on runtime 0.47.0, …`.
