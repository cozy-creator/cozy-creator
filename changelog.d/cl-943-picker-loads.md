Every model slot offers the models its checkpoint loads in, judged by headers against the slot's default (components read, classes, modules and their shapes, run data), never by family: Qwen Image's prompt enhancers offer Qwen3.6-27B, Klein's upsampler the abliterated one, and H3's base model never a checkpoint lacking its processor. `cozy model ls --fits <tool>:<slot>` lists them; `cozy run` refuses a choice that can't load before anything runs.
