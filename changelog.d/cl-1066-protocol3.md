The CLI and the page no longer ask Calcifer to prove "project storage protocol 3" before project requests, and send no `cozy-project-storage` header: one round trip fewer per CLI project command. `GET /v1/project-storage` is gone. One check stays: before a passphrase or recovery secret leaves, the CLI and the page read `GET /v1/status`'s new `os_user` and send nothing unless it is their own OS account ("The Cozy answering here runs as another account on this computer, so nothing secret was sent to it.").
