A package's name on the canvas takes the version its description writes after it as a word of its own, so Qwen-Image-2512's package reads Qwen Image 1 and Qwen-Image-2.1's Qwen Image 2.1, apart in Tools and on a box's tool line (cl-1182, Paul 11-17: "We should probably call it 'qwen image 1' to avoid confusion"). `cozy explain` names each tool as the page does (`Qwen Image 1 · Image`), and a tool's first sentence keeps a name with a dot in it whole (FLUX.2, Qwen Image 2.1).
