A node open in Focus is at `/p/<code>/nodes/<name>` (cl-1209, Paul 11-18): a double click, a row of the Assets drawer, a landed take's View and its address opened as it is all land there, a rename takes the address with it, and Back, Forward and a reload find it. `/p/<code>/assets/<name>` is no address: Calcifer answers it 404 like any unknown path, with no redirect. Calcifer now serves the page only at its own addresses (a project's `/p/<code>`, a node, and the drawers), so any other path under `/p/<code>` is 404 too, and `/settings` with no project open reloads instead of answering 404. The Assets drawer stays at `/p/<code>/assets`, and the Calcifer API's `/v1/projects/{id}/assets/…` is unchanged.
