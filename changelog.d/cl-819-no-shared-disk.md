The CLI shares no disk with Calcifer. Local code (`cozy run ./dir`, `--describe`, `package install ./dir`, `model quantize --package ./dir`) goes by content, as its package's tree, and Calcifer works from its own copy. `cozy package lock` and `publish` get their `uv.lock` back from Calcifer and write it into the folder. A project is its id, kept in `project.db`, and is named by its name or id with `-p` or `COZY_PROJECT`: the folder you're in no longer names one. A moved project folder keeps its id and its render; a copy gets its own. A run's outputs name no path of Calcifer's: `-o <dir>` on `cozy run` and `cozy run show` downloads them by their digest. `cozy package install` of local code keeps what the machine read of it, as a run's install does. A path on your tool list is refused: local code is a project's. `--file clip.mp4#t=a,b` is gone: a box mention names a video's frames (`<clip:48-144>`).
