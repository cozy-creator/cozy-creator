A LoRA added to a box (picked or dropped) puts its Hub trigger words after the box's prompt, once, as plain text. Each LoRA beneath a box shows its trigger words; one clicked goes at the caret of the prompt last typed in. Any prompt of the box that says an attached LoRA's trigger draws it in a token colour, typed or appended; removing the LoRA leaves the words and drops the colour. `cozy run --lora` and `cozy box set` leave prompts as written.
