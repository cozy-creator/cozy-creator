Projects: project.yaml is gone. There is no YAML export or import (`GET`/`PUT /v1/projects/{id}/yaml`) and no project.yaml drawer in the page; a project is its `project.db`, edited through the page and Calcifer's API. A folder with an old `project.yaml`, `project.lock` or `project.canvas.yaml` and no `project.db` is simply not a project: `cozy new --unencrypted` makes one there and leaves those files alone. A render keeps a snapshot of the project's boxes, not YAML text (cl-930).
