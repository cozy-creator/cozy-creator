A function that calls another package's function gets that package's models ready too (cl-1123). An Orbit box's predicted render brings MiniMax H3's text encoder, VAE and audio VAE to its machine, then both of H3's transformers in the background, before Render; a real Orbit run fetches them while it starts, not when its H3 call does. The machine walks each call into another package of the run's environment, and that function's own calls in turn. A call whose request is built in code gives its rules no answer, so what each function it may call reads in common is waited for and the rest comes in the background.
