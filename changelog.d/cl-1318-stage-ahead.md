A box predicted onto a machine whose GPU can't take its model yet (another model holds the room, the card is too small, or a run holds the GPU) now gets its weights read into RAM ahead, within the host's memory budget and given back first when memory is needed, so its render loads at the speed of PCIe instead of the disk. Where the GPU is free of runs but can't hold the model whole, its executor starts and its models are built in RAM ahead too. A tool put on a box, or a single edit, is predicted at once instead of 300 ms later, and a download whose bytes are all present no longer returns up to 250 ms late.
