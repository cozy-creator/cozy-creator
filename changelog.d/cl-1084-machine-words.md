What a machine says about a run reads as plain English, and names other runs as you know them: a queued run says "waiting for LAB2-12 to finish with this machine's CPU" instead of "queued: position 1 in the queue, for this machine's CPU: run-94c8de… holds its one CPU slot" (its place in line is its status, "Queued, 1st in line"); a full disk says what the render needs, what Cozy can free, what fills the disk and the disk to rent, in GB, with no `cozy` command to paste. Downloads, installs, missing models, sign-in and GPU failures read the same way.
