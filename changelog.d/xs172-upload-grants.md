`cozy model upload` from a slow or loaded computer no longer fails with `403 ExpiredRequest`. Every PUT of an object that took longer than 30 s to send was cut off and sent again: the client counted 30 s from the request's start to its answer, never restarting it while bytes moved. Each attempt read its object from disk again, progress counted the resent bytes (100% long before the end), and the presigned grant from the first HEAD expired after 10 minutes. Now a request fails only after 30 s with nothing sent or received. Each PUT uses the grant minted just before it; a retry, or storage refusing the grant, asks for a new one; each retry says `attempt 2/10` in the run's log; and a failed attempt's bytes no longer count as progress. Package publish asks the Hub for a new file grant when the store refuses one.
