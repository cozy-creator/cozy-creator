A tool goes on a box of the kind it makes. A tool of another kind let go on a box holding pictures or takes (the Video tool, H3 or Orbit, on a picture) makes a new box of its kind beside it that mentions the picture, and the picture stays as it was; an empty typed node still refuses it. Calcifer's `asset_tool_kind` refusal now reads what a tool makes when the project hasn't yet, so a tool of another kind can't be put on a box through the API either, and the refusal's `metadata` says what the tool makes. An image tool on a picture still starts from it (`<self.N>`).
