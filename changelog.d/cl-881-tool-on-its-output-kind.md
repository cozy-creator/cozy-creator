A tool goes on a box of the kind it makes. Let go on a box of another kind (the Video tool, H3 or Orbit, on a picture; an image tool on a video), it changes nothing and makes no box, and a note at the bottom left says why ("Orbit makes video: drop it on a video box"). Calcifer's `asset_tool_kind` refusal now reads what a tool makes when the project hasn't yet, so a tool of another kind can't be put on a box through the API either, and the refusal's `metadata` says what the tool makes. An image tool on a picture still starts from it (`<self.N>`).
