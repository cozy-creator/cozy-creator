A rental that has a box's predicted render's weights loads them while its GPU is idle: the render's executor is started, its models built and their weights on the GPU, so the render's first step loads nothing. Any call of another model takes the GPU back at once, the load never keeps a rental up, and it never takes memory another project's model holds. `cozy machine show` says `loading`, `loaded` or `evicted` for each predicted request. A computer made dedicated (`cozy machine update local --mode dedicated`) does it too.
