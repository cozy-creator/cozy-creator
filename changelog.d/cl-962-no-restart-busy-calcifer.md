A `cozy` of another version never restarts a Calcifer someone uses (an open page, a run going, a request in the last 10 min), nor one it is not the installed binary of: it says "Calcifer here is <v>, this cozy is <w>; run the matching cozy, or `cozy restart` to switch" and exits. `cozy restart` is the explicit switch. Calcifer says who uses it at `GET /v1/activity`.
