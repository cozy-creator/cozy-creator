A locked encrypted project, or one locking, says nothing of itself outside it (cl-1130): a machine lists its run as "a locked project's run" with its state alone (no record, id, name or target), a message naming its run says only that, and the projects index and a project's address leave out its key. A run's waiting or held text names another project's run only as "another project's run", and the machine's log names no project's run as it queues. While a lock waits for its runs to end, the project's page says a run is still finishing, not that an app holds its files.
