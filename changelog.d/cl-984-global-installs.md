Installed packages, models, LoRAs and PyTorch are the machine's again, shared by every project: a second project's first run of something installed downloads and builds nothing. A project keeps only its own data (its page state, run history, inputs, outputs and a run's scratch), encrypted where the project is. TensorD's bookkeeping of a project's stored files (what its runs read and wrote) lives in the project too, and a legacy run's outputs leave the machine with its history. Once an encrypted project is locked, nothing of it stays on the computer outside its folder: Cozy Creator keeps only where the folder is, so the page can offer Unlock.
