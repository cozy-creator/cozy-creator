`cozy machine ls` and `machine show` say when a machine is held by hand on software it keeps, and name `cozy machine update <machine>`, which lets it follow again. In a dev home, `local`'s TensorD moves to the Cozy Creator installed here once this computer is at rest, as Calcifer's own update. `scripts/dev-local.sh` follows its RC branch's head itself (one build for merges in quick succession), restarts Calcifer only when it serves nothing, and logs the commit, CLI, Calcifer and local TensorD versions after each install.
