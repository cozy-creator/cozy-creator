TensorFS reads some rows of a stored tensor without decoding it (tfs-303): `Checkpoint.rows(component, key)` says how it cuts (rows along its first dimension, the encoding's tile, each part's bytes per tile or whole), and `Checkpoint.read_rows` and a varena Source's `read_rows` fill caller-owned host or CUDA outs with only those rows' stored bytes, several tensors in one read on the caller's stream; the Source serves them from its kept page by DMA when it holds the stored bytes. Each scheme declares how its parts follow the rows; plain, `fp8.rowwise`, `int8.convrot`, `nvfp4` and `w4a8.convrot` do.
