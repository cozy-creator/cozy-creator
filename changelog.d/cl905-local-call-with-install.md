Local code's call no longer waits for its install. The first run of local code on a machine sends its install and, at once, its call, bound to what the static describer reads; the machine builds the environment once, in its install line, and the call goes on as soon as it's there. Before, the call was sent only after the install ended and its answer came back (3.9 s of the `lines` cell's gap); a project's render of local code waited for it the same way.
