LLM tools on the canvas (xs-204). A tool whose result is words is a tool like any other: it's listed under LLM, goes on a Text box (its words become the prompt), and each render is a new version showing its answer, on the box and in Focus. A tool let go on a box of another kind it can read makes a new box of its own kind beside it that reads that box: an LLM on an image or a video starts a text box whose prompt mentions it, with the caret there to ask, and an image-to-video tool on an image starts a video box. Where a tool can't read a box at all, nothing changes and a note says why. `POST /v1/projects/{id}/assets` takes `reads`, and a version of words gives its `text`.
