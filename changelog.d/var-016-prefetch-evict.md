A model whose weights don't fit beside its working memory now copies its next block while the current one computes. Varena's fill ahead makes its own room, taking what that block's demand would take, starting with the block just used (needed furthest ahead), and waits off the critical path for the GPU to finish with it; before, it only used memory already free and declined every time, so each block was copied on demand with the GPU idle. H3 15 s on a 24 GB card re-copies about 20 GB a step.
