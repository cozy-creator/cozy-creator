Packages without TensorHub (cl-1127). `cozy package install <git URL>[@ref]` installs code from a public repository (`https://github.com/<owner>/<repository>[@<ref>][/<folder>]`, a GitHub `/tree/<ref>/<folder>` link, or pip's `git+https://…#subdirectory=…`), and `cozy run` and a project's `with:` take the same spelling: this computer fetches it at an exact commit and sends it to the machine by content as local code goes, so no machine needs git or the repository's host; `cozy package ls` lists it as `git+<url>@<commit>`, and installing again moves it. A release this computer holds (kept behind any install of it) installs on another machine from here by content, the Hub up or down; with the Hub unreachable, a lock resolves from what uv holds here and `cozy machine update` takes the software target this computer last read.
