TensorFS takes one spelling for a model and its checkpoint (xs-220, hack audit tensord #9): `model_id`, never the old `repo_id` keyword (`download_file`, `upload_folder`, `Writer`, `Endpoint.resolve`, `CheckpointItem`) or `Checkpoint.repo_id`. `Endpoint.resolve` answers `checkpoint`, no longer `commit` beside it, and the executor's `checkpoint_item` frame names `model_id` on the wire. A resolve reads the Hub's `commit` alone. A caller still passing `repo_id` gets Python's unexpected-keyword error; the Runtime moved to `model_id` with cozy-runtime #2311.
