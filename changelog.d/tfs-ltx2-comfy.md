TensorFS reads LTX-2.5 in ComfyUI's two files, Lightricks' own layout (`ltx2.comfy` for the DiT, `ltx2.comfy_gemma` for Gemma 4), bf16 or int8_convrot, each uploaded on an LTX-2.5 base: the text connectors are split between the files, so each takes the rest of `connectors` from the base, key by key, and is refused without one. A converter table may now split one prefix among components by their rows, and name rows its source keeps in another file (`base`).
