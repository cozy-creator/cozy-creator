A dev home (`dev = true` on an RC build) can name a packages checkout, `[calcifer] packages = "<dir>"`: each first-party package it holds runs from its source wherever its unversioned name is asked (CLI, page, agent API), its run saying `<package> from source: <branch> @ <commit>`, and its packages call each other from it. `name@release` and everything else come from the Hub. With a checkout, `local` follows the RC's Runtime and TensorFS, moving only after a minute with nothing run.
