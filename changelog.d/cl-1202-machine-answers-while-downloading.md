A machine answers while its models download (cl-1202). Its Status reads checkpoints off disk instead of opening them, so reading it writes nothing to the store and waits on none of the store's locks. A model's record no longer flushes the whole disk while other downloads wait on it. The machine measures each package environment once per change instead of walking it again every 64 MB the disk moves. Reads of its run journal (Status, a run's state, its logs) use a connection of their own and wait on no commit, so a commit waiting for a busy disk delays only other writes; on a rental's disk, which no host crash outlives, the journal no longer flushes each commit.
