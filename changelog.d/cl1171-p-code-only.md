A project's only address is `/p/<code>` (cl-1171): the page, its links and `cozy open` never say `/projects/<id>`, and Calcifer answers `/projects/<id>` 404 like any unknown path; the Projects drawer stays at `/projects`. `/p/` takes a code alone: a project's id or name there opens nothing. Every project has a code. A locked encrypted project is listed by the id and code in its keybag, never a `locked-` handle, so its tab and the Projects list open it at `/p/<code>`, where it unlocks. A keybag locked before codes were kept there gives one derived from its project's id, which its first unlock keeps. A plain project whose `project.db` can't take its code still gets one in the index. Old `#/…` hash links are no longer turned into paths.
