A machine never runs a root wider than it has proved faster: one GPU, and a wider width only once that function timed faster there than on one GPU (a `--gpus N` run times it), or a release proved it faster for that function on that card and link (TensorD's `KNOWN`: H3 at two GPUs on RTX 4090 over PCIe and on H100 over NVLink or PCIe). So H3 on a pair no release measured runs on one GPU, and a second queued job takes the other. `--gpus N` is honoured as before.
