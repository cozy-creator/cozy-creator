A project's own models count on this computer again. Its runs download into the project's own storage, and `cozy machine show local` and the planner read only the machine's: what a project held was listed nowhere, and its next job was placed as though it had to download everything. Now each unlocked project's engine on this computer says what its own storage holds: `machine show` and `machine ls` list its public Hub models (never which project, a local alias, or a private or uploaded release), and the planner counts them for that project's jobs. A locked project is never opened for this. Upcoming and prepare lists for a project go over its own link into its own engine. Static descriptions of a project's local code are kept in the project's own storage, never in Calcifer's.
