A package release carries its own benchmarks (cl-1024, Paul 11-15): `cozy package publish` attaches the package's `benchmarks.json`, which `cozy package benchmarks` writes from a project's warm runs of it on GPUs, and first-party releases carry the release gate's. Estimates (placement, the time beside Render, a slow run's warning) stand on the user's own runs and these benchmarks only, never anyone's run reports, and the compiled-in table is gone.
