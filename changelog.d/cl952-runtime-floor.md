A machine runs only a package release its Runtime can run. A run whose release needs a newer Runtime than its machine's moves the machine to the newest one that runs it first, a release, or on the open RC its build, and says so (`upgrading vanitas's Runtime 0.45.1 → 0.47.0.dev2260 for minimax-h3 0.12.0rc3`). A machine held on its software by hand refuses instead, naming `cozy machine update <machine>`; another computer's machine takes the newest release its Runtime runs. `cozy package publish` refuses a package that imports from `cozy_runtime` what its `cozy-runtime` floor lacks, naming the floor that has it. The open RC's Runtime is a dev release of the minor it makes (`0.47.0.dev2260+g1a2b3c4d`), which a floor can name; it runs released packages whatever their cap.
