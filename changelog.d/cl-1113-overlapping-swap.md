Updating or restarting Cozy no longer takes it offline: `cozy calcifer` is a stable parent that keeps the port, lock and bearer, and each new version starts beside the running one and takes over once ready (`POST /v1/restart`, used by `cozy restart`, `cozy update` and Cozy's own updates). Nothing is refused meanwhile, and a page carries on without "Cozy is offline". A new version that doesn't start leaves the running one serving, with its binary put back (cl-1113).
