Every phase of a run says what it is with its numbers. An install says each step (`installing _/fibo-2 0.7.0 on this machine: installing its dependencies (3 of 5)`), the plan is `preparing the plan for <package>`, and a run out of its machine's queue whose executor starts is `starting` (a new machine state) while it imports its package (`importing <package> (1.9 GB of its files)`) or starts its executor, then `loading the models`. A Runtime count of bytes (`loading <component>`) is bytes with a rate, and a call's weights arriving show on its root's progress, so an H3 shot says its segment's download in bytes. The page says every stage the Runtime, packages, TensorD and Calcifer name from one map, `web/app/src/panels/runs/stages.json` (its words, phase and what a count counts), which the release gate reads too.
