Host RAM has one owner across a machine's executors: each process's host tiers share a host ledger page, an idle process gives its pinned pages back to a call that is short, and TensorD ends an idle executor when that isn't enough, as v1 did at a model switch. A tier's room is its cgroup as the kernel accounts it, with clean page cache counted as reclaimable, and the computer's reserve is kept once: by the contained machine's `memory.max`, or else by the tier, never both. A cold store read goes through the page cache only into memory nothing holds, so a store larger than RAM streams O_DIRECT instead of thrashing the cache.
