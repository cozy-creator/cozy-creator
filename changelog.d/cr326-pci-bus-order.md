An executor's seal sets `CUDA_DEVICE_ORDER=PCI_BUS_ID` (cr-326): CUDA then numbers a machine's GPUs as nvidia-smi and the machine do. On a computer with unlike GPUs, CUDA's default order is fastest first, so an executor sealed to GPU 0 could run on another GPU than the one the machine counted its memory on. The h3-group gate cell also checks that a run on the second GPU alone records that GPU's name, power limit and MIG mode, as `nvidia-smi -i <uuid>` reads them.
