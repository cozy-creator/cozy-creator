The machine picks each model's lane from the release's lanes, its GPUs, what it holds and the function's tolerances, and the Hub only lists them. A package's `min_bits` and `phase` now count: Klein's prompt upsampler (`min_bits=4`, decode) runs its 4-bit lane, and a `min_bits=4` model takes 4 bits on FP4 tensor cores or when its 8-bit lane is larger than the GPU. Free VRAM never lowers a lane, so the same machine always gets the same lane. With the Hub unreachable, a model is served from the best lane already downloaded, with a warning. Needs a Hub that lists lanes; an older one is refused.
