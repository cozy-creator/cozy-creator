Calcifer, TensorD, the page: a box's machine gets ready before Render (cl-1104). While a page shows a project, Calcifer guesses the machine a render of each box would go to, by the quote a render uses, and has it install the tool's package and fetch the models its function reads, in the background (`PUT /v1/prepare`). On the machine that is no job: behind every run's downloads and guesses, never a rental's use or its idle clock's restart, its build gives the install line to a run's, and what only it brought is the first to go when a run needs the disk. A box whose checkpoint changes keeps what both read coming and stops the rest; a deleted box's prefetch stops. The box says "Ready on kamitsure" beside Render, and its render goes there unless another machine finishes it clearly sooner.
