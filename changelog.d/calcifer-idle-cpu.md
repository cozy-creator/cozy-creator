Calcifer no longer reads every run a machine ever had to picture it: what its own runs put on each machine is folded once and then only from what is new, so machine lists, `cozy machine show`, `cozy doctor` and the page's event stream answer at once on a long history instead of keeping a core busy. A request or background task that takes a second or more says so in `~/.cozy/calcifer/health.log` (method, route, milliseconds).
