An import now stores a model component's stray 32-bit weights at 16 bits when the rest of that component is BF16 and the class it loads into does not keep them at F32 by its own published rule (Diffusers' `_keep_in_fp32_modules`, Transformers' `_keep_in_fp32_modules_strict`), as its authors' loader would. Krea 2's transformer is 642 MB smaller on disk and on the card. A component stored in F32 (a VAE, say) stays F32, and the import says in one `width:` line what it did with each component.
