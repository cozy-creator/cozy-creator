Upgrading from 0.25 or an 0.26 RC deletes the run history from before projects kept their own (cl-1003): every project's old runs, ended runs outside a project and ended rentals' records go, and Calcifer's store keeps only what is live (version 9). Project folders, their `project.db` and their files stay. A file a project left only in this computer's machine store is copied into it first; a locked encrypted project's at its next unlock. The `state.db.pre-*` copies beside the store are deleted. `cozy status` and `cozy doctor` no longer list legacy history; `cozy doctor` and the project's page say when files of a project were lost before the upgrade.
