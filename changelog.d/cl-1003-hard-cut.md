Upgrading from 0.25 or an 0.26 RC deletes the run history from before projects kept their own (cl-1003): every project's old runs, ended runs outside a project and ended rentals' records go, and Calcifer's store keeps only what is live (version 9). A render going at the upgrade is dropped, and renders again. Project folders, their `project.db` and their files stay. A file a project left only in this computer's machine store is held there at the upgrade and copied into the project at its next open (an encrypted one's at its unlock); a folder that can't be written then keeps it held, and the project's page says why. `cozy doctor` says how many projects' files are held and how to let them go. The `state.db.pre-*` copies beside the store are deleted. `cozy status` and `cozy doctor` no longer list legacy history.
