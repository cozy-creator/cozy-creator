The end of a run says what it does: TensorD names `encoding the outputs` and `saving the outputs` after its executor replies. The time left keys on the stage a run is in without what passes inside it (`denoise / loading transformer`, `… / compiling sol-attn`), so a model paged in each step no longer restarts its stage's estimate each step. The page's words cover the Runtime's new stages (`constructing <model>`, `capturing graphs`, `checking <kernel>`, `opening <kernel>`, `starting the GPU`, the group's start and links, `warming <package>`, kernel sets compiled or copied). e2e checks that a run whose fallbacks the Runtime recovered from warns of nothing, in its log, on its record and on its box.
