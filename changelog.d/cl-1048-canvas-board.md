The canvas is drawn by one new PixiJS layer: a box looks the same at rest, under the pointer and while it's pulled, so nothing flashes on hover and a resize holds until it's let go. A selected box gets one thin blue line, as in Figma, and an X beside a box's tool takes the tool off. A computer without a GPU draws the canvas in 2D and opens projects faster. Screen readers get a list of the boxes and a Cancel for each render.
