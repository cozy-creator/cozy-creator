GPU memory is rewritten around one owner. Varena alone decides what stays on the card, so models load and swap with less reading from disk and small cards run what used to run out of memory. Processes on one GPU hand idle memory to each other, and a game or other program that needs the card gets idle memory back within about a second. Idle CUDA graphs give their scratch memory back and remap it in milliseconds on the next replay. `vt.offload(pipe)` runs stock Diffusers pipelines on a small card with automatic graphs, falling back to eager whenever a graph can't be trusted. Engines without Torch can use the same memory through a C, Rust or Python API (`crates/varena/PUBLIC-API.md`). Needs the matching Runtime.
