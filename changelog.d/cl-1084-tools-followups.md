Typing `<` in a box's words offers only what its tool can use: SDXL's lists no images, a tool that reads images lists them. Each tool has one name, its model as its package's description writes it (MiniMax H3, Qwen-Image-2.1, BiRefNet, MOSS-Image, SDXL), in Tools, on a box's tool line, in notes and in why something is struck through; a label that names its model already is said alone (MiniMax H3 Edit, never "Minimax H3 · MiniMax H3 Edit"). A Tools group lists what makes something new first, then what edits, each by name (cl-1084).
