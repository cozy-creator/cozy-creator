# TensorFS Python bindings

TensorFS is a Rust library with Python bindings and the `tfs` command-line tool for
loading, storing and sharing model weights.

The [TensorFS overview](https://github.com/cozy-creator/cozy-creator/blob/master/crates/tensorfs/README.md),
[Python guide](https://github.com/cozy-creator/cozy-creator/blob/master/crates/tensorfs-py/API.md)
and [format specification](https://github.com/cozy-creator/cozy-creator/blob/master/crates/tensorfs/spec/cozytensors.md)
cover the shared library and format. Python-specific documentation lives alongside these bindings.
